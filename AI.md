# AI Development Notes

## AI Tools Used

ChatGPT was used as an AI development assistant during the implementation of this project.

## How AI Was Used

AI assistance was used for:

- React component implementation
- CSS styling and responsive layout
- Form validation logic
- Express API implementation
- Debugging frontend and backend issues
- Improving user interaction states
- Clipboard copy functionality
- Project documentation
- Git and GitHub workflow guidance

## Human Review

AI-generated suggestions were reviewed, tested, and adapted during development.

The final implementation was run locally and manually tested to verify:

- Responsive layout
- Form validation
- API communication
- Claim-code generation
- Loading state
- Error state
- Copy functionality
- Claim-again functionality

## AI Mistake / Correction

During development, some AI-generated suggestions were not suitable for the current project setup or assignment requirements.

These suggestions were reviewed against the existing project and assignment requirements rather than being blindly implemented. Unnecessary changes were removed or avoided.

## Development Approach

AI was used as a development assistant, not as a replacement for testing or decision-making.

The final code and project structure were reviewed manually before being committed to GitHub.
